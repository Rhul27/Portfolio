// How I build

LLMs are easy to demo, hard to ship

These are the principles I use to turn model calls into software people can rely on.

01

Orchestrate, don't prompt

Stateful graphs with clear stages, typed state and structured outputs beat one giant prompt.

02

Ground everything

Retrieval, source citations and validation keep answers tied to real data.

03

Design for failure

Retries, persistent jobs, guardrails and human-in-the-loop checkpoints.

04

Watch the cost

Per-stage model routing and token accounting so every request is profitable.
